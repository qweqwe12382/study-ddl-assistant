## ▶️ 启动后端

PowerShell：

```powershell
$env:PYTHONPATH = "$PWD\backend"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload
```

服务启动后访问：

- 健康检查：<http://127.0.0.1:8000/api/health>
- Swagger：<http://127.0.0.1:8000/docs>

首次启动会自动创建账号库 `data/auth.db`、现有数据工作区 `data/app.db` 和 `data/uploads/`。第一个注册账号接管已有 `app.db` 并成为实例管理员；后续账号使用 `data/users/<workspace>.db` 独立保存课程、资料、任务、计划和智能体记录。

## 🔐 首页与邮箱账号

- `/` 是面向大学生的公开主页，`/register` 和 `/login` 提供邮箱注册登录，登录后的学习总览位于 `/app`。
- 密码使用随机盐 `scrypt` 哈希保存；浏览器会话使用可撤销的 HttpOnly Cookie，写操作还需通过 CSRF token 校验。
- 每个账号使用独立 SQLite 学习工作区；新上传文件按账号目录保存，开发环境“重置测试数据”只处理当前账号的数据和文件。
- 外部 AI 密钥是实例级配置，仅第一个管理员账号可读取掩码状态和修改；普通学习账号不能改变全局 Provider 配置。
- 当前没有邮箱验证码、找回密码或生产级账号运维能力。它仍是本地开发与评审版本，不应只因增加登录功能就直接公开部署。

## 🗓️ 课表与考试

- 登录后访问 `/schedule`，可按第 1—30 周查看星期一至星期日的课程；课程时间支持起止周、每周/单周/双周、教室和备注。
- 同一周次真正重叠的课程会被拒绝；单双周错开的同一时段允许分别保存。课表记录复用“设置”中的课程名称、教师和颜色。
- 考试可记录类型、开始/结束时间、考场、座位与备注，页面按北京时间显示倒计时，并可选择查看已结束考试。
- “接入教务”提供两种方式：读取标准 iCalendar（`.ics`），或从本机后端一次性连接南京理工大学旧教务系统并读取指定学期的课表与考试；两种方式都先预览、再勾选确认，无需预先手工建立课程。
- 南理工账号、密码和上游 Cookie 只在一次请求与最长 5 分钟的验证码会话中存在，不写数据库、文件或浏览器存储；原始教务 HTML 也不保存。旧教务端点使用 HTTP，页面会明确提示传输风险，并要求用户确认处于可信校园网或学校 VPN 后才登录。
- 确认后的课程、考试与同步身份保存在当前邮箱账号的本地 SQLite 工作区。重复导入会区分新增、更新和无变化；若学生已在本地修改、原日程已删除或时间冲突，则停止覆盖并逐项说明。
- 课表与考试的编辑和删除使用身份、版本及 `If-Match` 校验，旧页面不会覆盖较新的修改；数据继续保存在当前邮箱账号的独立学习工作区。
- 当前南理工适配器是非官方、用户主动触发的一次性本机直连，不会记住凭据、静默后台同步、自动删除本地日程、生成 DDL 或修改复习计划；学校端点与页面结构变化可能导致暂时不可用。

## 📱 Android 移动伴侣

- `android/` 是原生 Kotlin + Jetpack Compose 应用，不是网页套壳。当前提供登录、今日学习时间轨道、按周课表、考试倒计时、DDL 队列和一键完成任务。
- 安卓端不采集南理工教务凭据，只读取用户已在网页版确认同步到个人 SQLite 工作区的课程与考试，避免多个终端重复传递教务账号密码。
- 登录密码不保存；Cookie 与 CSRF 仅驻留进程内存，退出或应用进程结束后清除。手机只保存服务地址和当前教学周。
- Release 构建只允许 HTTPS。Debug 构建可通过 ADB reverse 连接 `http://127.0.0.1:8000`，代码仍会拒绝公网 HTTP、带账号的 URL、查询参数、锚点和任意路径。
- 构建、USB 连接和隐私边界见 [`android/README.md`](android/README.md)。

## ⚙️ 配置

复制 `.env.example` 为 `.env` 后按需修改。也可以直接打开前端“设置”页，在“外部 AI 配置”卡片中填写 API 地址、模型名称、API Key、超时和重试次数并保存。保存接口只返回掩码提示，不会把完整密钥回显到页面；密钥写入项目根目录 `.env`，不要提交到 Git。

| 变量 | 默认/示例 | 作用 |
| --- | --- | --- |
| `DEMO_MODE` | `false` | 是否幂等加载脱敏演示数据 |
| `LLM_BASE_URL` | 留空 | 可选的 OpenAI-compatible API 地址；留空时使用 SDK 默认地址 |
| `LLM_API_KEY` | 留空 | 配置后允许使用外部 OpenAI-compatible Provider |
| `LLM_MODEL` | 留空 | 外部 Provider 的模型名称 |
| `LLM_TIMEOUT_SECONDS` | `30` | 外部模型单次请求超时 |
| `LLM_MAX_RETRIES` | `2` | 外部模型失败后的重试次数 |
| `LOG_LEVEL` | `INFO` | 后端日志级别，可改为 `WARNING` |
| `CORS_ORIGINS` | 本地前端地址 | 前端开发服务器允许的来源 |

默认使用无需网络和密钥的本地规则 Provider。配置外部 Provider 后，用户仍需在每次抽取前主动选择“外部 AI API”并确认隐私提示，资料文件名和解析正文才会发送到外部服务。设置页保存后会立即更新当前后端进程，无需重启；重新启动时仍会从 `.env` 加载。

## 🤖 M4 AI 抽取与人工确认

M4 复用 M3 保存的 `extracted_text`，默认使用无需网络和密钥的本地规则 Provider；可在设置页填写 `LLM_API_KEY`、`LLM_MODEL` 等配置，资料页随后可以按次选择 OpenAI-compatible Provider。外部选项未配置时自动禁用，调用前会再次提示正文外发范围。所有 Provider 的输出都会经过 JSON/Pydantic 校验、日期和时间校验、相对日期解析、多日期冲突检查、来源原文回溯和置信度标记。

抽取结果不会直接写入正式任务。资料库中点击“AI抽取”后，用户可以修改任务名称、类型和截止时间，勾选需要保留的候选项，再点击“确认并创建任务”。对应接口为：

- `POST /api/materials/{id}/extract`：生成或更新抽取预览；
- `GET /api/materials/{id}/extraction`：读取最近一次抽取结果；
- `POST /api/materials/{id}/extraction/confirm`：人工确认后创建正式任务。

低置信度、缺失日期、无效日期、日期冲突或来源片段无法回溯的候选项会进入“需复核”状态。模型调用失败或结果不是合法 JSON 时会保存失败原因，用户仍可手动补充正文或继续使用本地规则 Provider。

本轮优化已补充已确认状态保护、批次级幂等、防重复任务、人工修改快照、课程/标签落库和英文/相对日期解析。已验证：后端 `pytest -q` 通过 33 个测试，前端 `npm.cmd run lint` 和 `npm.cmd run build` 均通过。

M8.26“近期复习行动板与计划执行层”把复习计划页从默认大表格收敛为普通学生能立即执行的下一步。简洁视图从现有计划事实中按“已延期—今天—近期—稍后”固定排序选出下一项，并最多展示 7 条计划项与剩余数量；它不把条数称作自然周，也不伪造 AI 优先级、风险或准备度。完成动作复用现有计划更新接口，不做乐观完成，且只提交服务端已保存的计划项基线，避免把详细表格尚未保存的编辑一并写入；失败时页面状态保持不变。详细管理继续保留生成、校准、导出、归档、来源与完整编辑。`plan_id/item_id` 深链会真实聚焦，`weekly_plan_delays` 按最近 7 个中国本地日期汇总全部未归档计划，无课程归属的合法计划也能直接打开。隔离页面覆盖跨计划延期、完成焦点、服务失败、无课程计划和两种移动视口；`npm run verify` 通过，StudyPlans JS/CSS 为 13.80/4.50 KiB gzip，低于新增 16/6 KiB 预算。M8.26 未修改后端且未重跑后端测试。

M8.27“DDL 学习资料包与安全来源回路”把题目中的“DDL 与资料管理”从两张相邻清单收拢成可执行关系。任务页根据现有 `material_id` 和服务端资料列表，只展示三种可证实状态：当前资料可用时显示真实文件名与“打开资料”，资料已删除时只显示历史名称，未关联时明确提示编辑任务补充；不做同课程推荐、相似度或知识图谱推断。点击可用资料仍先调用服务端 resolver，前端只接受来源身份一致、路径固定为 `/materials`、查询仅含匹配 `material_id` 的目标，畸形响应或断连均停止跳转。隔离 SQLite 已验证可用、已删除、未关联、长文件名、简洁/详细入口与服务失败；375×840、840×375 无页面级横向溢出，关键按钮不小于 44px，健康页无控制台警告或错误。`npm run verify` 通过，Tasks JS/CSS 为 16.14/3.70 KiB gzip，低于 18/5 KiB 预算；M8.7 证据导航 6 项聚焦测试通过，150 项完整基线未重跑。

M8.28“首页 DDL 资料就绪带与共享安全导航”把 DDL ↔ 已关联资料关系前置到简洁首页：只消费现有 Dashboard 任务中的 `material_id/material_name/source_available`，分别呈现可用、历史删除、未关联和矛盾四态，不增加首屏请求或推荐算法。截止卡片采用语义化 `article` 与同级“查看任务 / 打开资料”按钮，窄容器自动减少列数；点击资料时重新向服务端解析，并与任务页共享固定 `/materials` 和唯一 `material_id` 的严格校验。新增 `navigation:check` 纳入 `verify`，覆盖四态和恶意/畸形目标；手机端保留 API 状态标签。真实页面验证了资料/任务定位、点击前删除、服务断开、长文件名和双视图，1440×1000、375×840、840×375 均无页面级横向溢出，新增按钮为 44px，健康页面无控制台警告或错误。`npm run verify` 与 M8.7 的 6 项聚焦测试通过，未改后端业务，150 项完整基线未重跑。

M8.29“不可复用来源身份与端到端导航保护”进一步保证这些入口确实属于原来的学习来源：资料、任务、计划、计划项和回执都持久化独立身份，resolver 与目标页面双重核对，旧引用不会打开删除后同编号的新对象。失效计划在简洁/详细视图都收起内容与操作，只留下明确提示和“清除定位”；旧建议不能执行在同号替代任务上。旧库只给当前实体补身份，旧计划导出不按裸编号冒用新资料名称。当轮完整后端 159 项及前端 `verify` 通过；隔离页面已验证删除重建、计划项重添与双视图阻断，用户真实库未迁移。

M8.30“多页面编辑保护与草稿恢复”防止后保存的页面覆盖先保存的内容。网站在任务、资料、计划提交时校验打开时的身份与版本；冲突后保留当前草稿，在活动弹窗内提供“查看最新内容 / 放弃我的修改并重读”，不自动覆盖或合并。资料候选同时校验所属资料与预览版本，旧正文不能确认成任务，同号替代资料也不能接管旧预览。该里程碑当时后端完整 183 项及前端 `verify` 通过；当前包含邮箱账号、课表考试、标准日历与南理工本机接入的最新 197 项基线见本文顶部。草稿仅在当前页面内存中保留，实际库升级、真实历史积累和辅助技术仍需继续验收。
