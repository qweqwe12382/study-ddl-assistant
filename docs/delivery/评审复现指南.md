# 评审复现指南

本文用于在本地复现一条不接触真实用户数据的学习闭环。命令均可从任意 PowerShell 当前目录执行；下面的路径以当前工作区为例。若工作区移动，只需替换脚本的绝对路径。

## 环境与依赖

- Windows PowerShell。
- Python 3.14.6，且项目根目录已有 `.venv`（脚本使用 `.venv\Scripts\python.exe`）。
- Python 依赖已安装，至少包括 pytest、FastAPI、SQLAlchemy、uvicorn；`verify-local.ps1` 会用 `pip check` 检查依赖一致性。
- Node.js 24.19.0、`npm.cmd`，以及 `frontend\node_modules`（启动脚本要求存在 Vite，完整验证会运行前端 `npm run verify`）。
- SQLite 随 Python/SQLAlchemy 使用，不需要单独安装。

## 评审场景与证据

以下场景对应隔离测试中的连续操作。操作顺序应保持一致，`X-CSRF-Token` 来自客户端 cookie；修改任务或资料时同时携带测试返回的 `If-Match` 版本标签。

| # | 操作 | 预期 | 证据对应 |
|---:|---|---|---|
| 1 | 调用 `GET /api/health` | 返回 200，`service` 为 `learning-assistant-api` | 测试 `health` 断言；运行输出与接口响应 |
| 2 | `POST /api/auth/register` 注册 `reviewer-smoke@example.test` | 返回 201，邮箱与请求一致 | `registration.status_code`、`registration.json()` |
| 3 | 带 CSRF 调用 `POST /api/auth/logout`，再访问 `/api/auth/me` | 登出返回 204，当前会话返回 401 | `logout` 和 `client.get('/api/auth/me')` 断言 |
| 4 | `POST /api/auth/login` 使用测试账号登录 | 返回 200，后续请求获得认证 cookie | `login.status_code`；客户端 cookie |
| 5 | 带 CSRF 创建课程“数据结构” | 返回 201，并取得课程 ID | `course.status_code`、`course_id` |
| 6 | 上传 UTF-8 文本通知，正文含“图遍历实验”和 2099-10-15 20:00 截止时间 | 返回 201；处理状态为 `processed`，抽取状态为 `ready` 或 `needs_review` | `uploaded` 的状态字段；`runtime_root/uploads/*.txt` |
| 7 | 读取 `/api/materials/{id}/extraction` | provider 为 `local-rules`，有 batch ID，恰好抽取一个任务候选，来源摘录来自原文 | `saved_preview` 与 `preview` 字段断言 |
| 8 | 用预览的导航身份和版本调用 extraction confirm，确认候选并添加“实验/DDL/图遍历”标签 | 返回 200，状态为 `confirmed`，创建一个正式任务 | `confirmation.status`、`confirmed_task_ids` |

| 13 | 请求任务 CSV、资料 Markdown、计划 Markdown 和任务 iCal 四个导出 | 全部返回 200；CSV 有 UTF-8 BOM；内容含任务/文件名/“复习清单”；iCal 含 `BEGIN:VEVENT`、`TZID=Asia/Shanghai`、`TRIGGER:-P1D` | `tasks_csv`、`materials_md`、`plan_md`、`calendar_text` 断言 |

## 证据边界

上述冒烟是 FastAPI `TestClient` 进程内接口测试，使用覆盖后的 SQLite 文件和上传目录，不能证明浏览器页面布局、真实浏览器 cookie 行为、前后端联调或移动端表现。要观察网页，必须另外运行 `start-dev.ps1` 后打开 5173 页面；这仍然属于本机服务检查。

导出的 iCal 只证明接口生成了含时区和提前一天 `TRIGGER:-P1D` 的日历文件，不等于操作系统日历已经导入，也不等于系统日历提醒已经实际弹出。系统级提醒需在目标设备中手动导入并单独验收。
