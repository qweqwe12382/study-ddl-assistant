# 学伴管家 · 视觉整理

本轮目标：专业、干练，保留学习产品的亲和力。面向大学生，页面的首要任务是帮助用户从资料和截止时间中找到下一步行动。

## 视觉基准

| 角色 | 取值 |
| --- | --- |
| 正文与标题 | 墨绿黑 `#182e29` |
| 主操作 | 深翡翠绿 `#196b52` |
| 页面底色 | 冷灰白 `#f4f6f5` |
| 内容表面 | 白色 `#ffffff` |
| 分隔线 | 灰绿 `#dce4df` |
| 次要文字 | 石板绿灰 `#5c7066` |

- 字体：Noto Sans SC 负责中文；Manrope 负责西文与数字。可变字重形成层级；标题 700–750，操作 600–650，正文 400–500。
- 布局：首页左侧大标题、右侧可交互任务预览；工作区以安静的侧栏、清晰页标题、重点任务和辅助信息依次展开。统一左对齐，正文控制行宽。
- 圆角：按钮与表单 6px，内容区 10px；只有主展示区使用轻微阴影。选中状态用实色与字重表达。
- 动效：保留用户操作后的反馈；移除首页循环漂浮装饰。尊重系统减少动态效果设置。

## 设计复核

不用金融后台的密集指标替代学习场景。首页继续展示真实可操作的课程任务示例，但将手账的旋转、枝叶、悬浮贴纸收敛为整齐的工作面板。视觉重点集中在标题的字形与版面比例，其余区域为内容服务。

字体按需子集化并随站点托管，许可和来源保存在 `frontend/public/fonts`。生僻字和用户输入由系统中文字体回退，不依赖第三方字体网络请求。

## 背景装饰补充

2026-09-19 按用户追加要求增加纸张与书页主题的背景层。首页和认证介绍区使用新生成的浅鼠尾草绿纸张浮雕图；工作区与通知展示区使用细线纸页路径；深绿底部横幅采用书页曲线。装饰沿内容边缘分布，中央文字和操作保持清晰。

网页仅增加一张约 25 KB 的 WebP 与两张小型 SVG；原始图片及生成提示词保存在 `frontend/src/assets/decor`。装饰不拦截点击、不参与屏幕阅读器内容、无循环动画；手机降低强度，高对比度和打印模式隐藏。
