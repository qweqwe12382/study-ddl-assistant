# 页面动效设计与验收

日期：2026-09-20。目标：在现有深绿、墨色与学习手账风格上增加表现力，让导航、展开与操作结果更连贯。

## 动效方向

主要视觉动作是“翻开学习手账”：公开主页和登录/注册页的手账示例进入视野后打开一次。标题与正文保持稳定，日常工作区使用短时过渡。没有增加持续浮动、闪烁、视差背景或新的动画依赖。

| 位置 | 动作 | 时长 |
| --- | --- | --- |
| 主页、登录/注册手账 | 以装订侧为轴轻微展开，配合裁切和透明度；只在进入视野后播放一次 | 640ms |
| 手账示例切换 | 页内轻翻与快速退场；主页的三项任务依序归位，最大延迟 70ms | 进入 240–260ms，退出 100ms |
| 工作区导航 | 内容轻移进入，侧栏/手机当前入口图标轻收定 | 页面进入 220ms，退出 80ms |
| 简洁/完整视图 | 白色选择滑块移动到新视图，保留键盘焦点与选中状态 | 240ms |
| 筛选、更多选项、记录展开 | 网格展开和收起，箭头同步转向 | 展开 240ms，收起 160ms |
| 任务列表与完成回执 | 列表项退出后其余项目归位；完成勾选描线，图标轻收定 | 列表 140–240ms，完成反馈 300–340ms |
| 按钮、进度及截止变化 | 短按反馈；进度条与时间标记跟随实际状态平滑移动 | 按钮 140ms，示例进度 320ms，专注进度 1s |

全部效果使用已有 Vue Transition、CSS 和浏览器 Web Animations API。没有增加接口调用、人工等待、动画定时器或业务状态延迟。

## 可访问性与中断

- 手账初始状态就是可见内容；不支持动画接口时保留静态内容。
- 尊重 `prefers-reduced-motion`。手账入场在该偏好下不启动；空间移动、描线和缩放通过现有媒体规则关闭或缩短，选中颜色与文字反馈保留。
- 手账入场期间发生点击、键盘焦点进入、页面隐藏、减少动态效果偏好变更或组件卸载时，立即取消并清理监听器。
- 屏外手账不会提前播放，且不因反复滚动重播。
- 连续完成不同任务或更新完成反馈时，依据任务与版本重新播放勾选反馈；回执容器的焦点行为保持原样。
- 没有改变输入框、按钮、对话框或任务完成的业务条件。

## 验收结果

### 自动化

`npm.cmd run verify` 通过，包含静态检查、**15 组行为契约**、生产构建和原有 gzip 预算。

新增 `check-motion.mjs` 验证：屏外等待、只播放一次、减少动态效果、不支持动画接口、正常结束、运行中取消、指针/键盘打断、页面隐藏、卸载、动画失败和观察器不可用时的回退。

最终资源检查：公共样式 32.73 KiB gzip，预算 34 KiB；首页 JS 41.73 KiB，预算 42 KiB；最大单个 JS 132.65 KiB，预算 136 KiB。公共样式相比上一轮增加约 0.20 KiB，没有提高预算。

### 浏览器实际操作

使用独立本地演示空间，检查桌面 1440×1000 与手机 390×844：

1. 主页手账入场期间观察到透明度、透视角度及裁切逐步变化；结束后回到 `opacity: 1`、无 transform 和无 clip-path，未留下动画样式。
2. 手机注册页手账起初位于视口外（顶部约 978px），保持静态；滚动后才出现展开效果。点击“专注时刻”立即中断入场，正常显示示例内容。
3. 连续切换“今天的安排/考前一周”后，选中状态、任务内容与完成计数一致，没有空页或残留双页。
4. 勾选示例任务后，完成数、描线和进度比例同步变化；切换截止延期后，日期文案与时间标记同步更新。
5. 手机切换完整视图时滑块实际移动；更多选项和资料筛选展开正常，Tab 可进入课程筛选，收起完成后面板高度为 0 且 `display: none`。
6. 从手机全部功能导航进入资料库时，工作区实际执行 220ms 的进入过渡；快速连续访问资料库、复习计划、总览后，仅保留当前页面。
7. 在隔离空间添加并完成 3 项动效样例；连续完成时回执文字更新、勾选再次播放，焦点落在完成回执，最终全部样例均已完成。
8. 专注页实际启动、暂停、结束并放弃短时测试；时钟与变换后的进度条随真实计时变化，没有写入虚构的专注时长。
9. 全部 8 个工作区路由完成桌面与手机宽度检查：页面正常加载、只有一个当前页面、根宽度不超过视口。最终浏览器错误/警告记录为空。

减少动态效果的生命周期由自动化验证，CSS 媒体规则已复核；本轮没有修改操作系统偏好。浏览器操作证据不等同于真实手机硬件上的帧率基准测试。

## 维护位置

- `frontend/src/directives/folioEnter.js`：可见性触发及中断清理。
- `frontend/src/styles.css`：共享节奏、页面、选择滑块、列表与操作反馈。
- `frontend/src/styles/landing.css`：主页翻页、勾选、进度与时间标记。
- `frontend/src/views/AuthView.vue`：登录/注册手账。
- `frontend/src/views/TasksView.vue`：连续完成时重播勾选。
- `frontend/src/views/MaterialsView.vue`：筛选展开结构。
- `frontend/src/views/FocusView.vue`：以变换更新专注进度。

新增动效应沿用这些节奏，并保留静态可读状态、减少动态效果与卸载清理，避免在每一个内容区重复添加入场动画。
