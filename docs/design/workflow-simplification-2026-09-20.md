# 基础操作流程与简化验收

更新日期：2026-09-20

## 日常使用，只记住这四条路径

| 想做什么 | 最短操作路径 | 自动处理的内容 |
| --- | --- | --- |
| 记下一件事 | 首页输入任务 → 回车 | 不必先选课程、日期、优先级或预计时长；需要时点“今天截止”“明天截止” |
| 开始做事 | 首页“开始专注 · 25 分钟” | 带入当前任务并开始计时；任务列表也能直接开始专注 |
| 完成一件事 | 首页“已完成”，或任务列表完成按钮 | 保存结果并显示下一件待办；基础完成操作不要求补写复盘 |
| 安排复习 | 复习计划 → 生成并保存计划 | 推荐资料、课程已有考试日期和每天 60 分钟先填好；没有资料时可带入待办 |

第一次添加资料：从首页粘贴通知，或在资料库上传文件，保存后直接核对。通知中的具体任务经确认后加入待办；纯学习内容可以直接选择“安排复习”。

没有这门课时，可在课程选择框旁新建课程。没有考试日期时，计划先按两周填写，也可以点“先安排一周”。“复习到哪天”是安排的截止日期，不代表修改课程考试时间。

## 这次减少了哪些重复操作

以下步数从对应入口已显示、内容可用时计算；输入正文、选文件和首次创建课程的工作仍然需要用户完成。

| 场景 | 原先的阻力 | 当前操作 |
| --- | --- | --- |
| 首页记任务 | 需要跳转或展开其他入口 | 输入后回车，不离开首页 |
| 开始专注 | 到专注页后再选择任务、开始计时 | 首页或任务行点一次，直接开始该任务的 25 分钟专注 |
| 首页完成任务 | 需要进入任务页再处理 | 点一次“已完成”，原地显示成功反馈 |
| 给任务设近期截止日期 | 先展开更多选项 | “今天截止”“明天截止”直接可见 |
| 已有内容生成复习计划 | 逐项选择来源、日期和用时 | 推荐范围与常用时间先填好，确认后点一次生成 |
| 只有待办、没有资料 | 复习范围为空，需要另找内容 | 自动选入该课程未完成的待办，并显示名称供核对 |
| 从计划页补充资料 | 返回后可能再次填写范围和时间 | 刚上传的资料自动选中，保留课程、复习期限和每天用时 |
| 专注页没有任务 | 需要先去任务页新增再返回 | 原地输入，点“添加并开始” |

## 页面信息优先级

- **首页简洁视图**先呈现实际待办、开始专注和完成操作；常规的预计时长补充提示不再占据主要位置。
- 有截止风险、需要确认的变更仍可在提醒区域查看。完整视图保留详细记录、分析和设置入口。
- 首页只保留与行动相关的任务和资料数量。已有任务时不重复展示入门教程。
- 复习计划把名称等低频配置放进“更多设置”，把推荐范围和时间放在前面。
- 新增的快捷按钮在手机上保留至少 44 像素的高度；专注与完成按钮可并排显示。

## 必要确认与异常处理

- 识别出的任务仍需要明确确认，识别不会自动写入待办。
- 对既有计划的调整和截止日期修改继续保留确认步骤。
- 过期、已完成或身份不匹配的任务链接不会启动另一件任务；专注页会提示重新选择。
- 完成任务仍校验记录版本，避免覆盖其他页面的修改。
- 正在计时的专注离开页面时仍有提醒；不足最低记录时长的专注不会伪造学习记录。
- 修复了任务完成触发计划调整建议时，首页摘要因缺失显示函数而读取失败的问题。

## 验收记录

在独立演示数据库内通过浏览器实际操作，没有更改用户原有业务数据。

| 实际操作 | 结果 |
| --- | --- |
| 首页输入任务、设为今天、回车提交 | 新任务保存，首页立即显示 |
| 首页直接专注与完成 | 绑定正确任务开始 25 分钟计时；完成后显示下一件待办 |
| 粘贴含提交期限的通知并核对 | 确认后生成正确任务和截止时间 |
| 添加课程考试后新建复习计划 | 自动带入同一课程的未来考试日期 |
| 按一周期限从推荐资料生成计划 | 保存成功，计划项可直接标记完成 |
| 新建课程并添加该课程待办 | 无资料时自动选入待办，计划生成成功 |
| 从任务行直接开始专注 | 正确任务直接计时；离开提醒有效 |
| 使用身份不匹配的专注链接 | 显示失效提示，不自动启动其他任务 |
| 专注页空状态新增任务 | “添加并开始”保存并启动该任务 |
| 计划页添加英语复习提纲后返回 | 保留课程、9 月 27 日期限、每天 30 分钟；新文件自动选中；生成两项复习安排 |
| 390 × 844 手机布局 | 页面无横向溢出；任务快捷操作、时间选择按钮均可点击，相关按钮高 44 像素 |
| 完成任务后查看完整首页摘要 | 记录、计划差异及依据正常加载 |

自动验证覆盖前端代码检查、13 组行为契约、正式构建与文件体积限制；相关后端测试共 20 项通过。此次验收没有使用真实教务账号测试学校系统连接。
