# 介绍页视觉升级与验收

日期：2026-09-20。范围：公开介绍页 `/`。沿用学伴管家的墨绿、纸张与学习手账视觉，增强主视觉、版式层次与交互展示。

## 页面表现

- 首屏采用原创立体书页主视觉：布面封皮、拱起的纸页、折纸阶梯、黄铜书签。大标题搭配一次描绘的下划线和两张纸签，强调“学习有序、行动清晰”。
- 学习日常以左右分栏呈现，右侧交互手账叠放在浅绿与米白纸页上。保留今天／考前场景、任务勾选、完成反馈。
- 使用流程改为可选择的三个步骤。对应展示资料归集、截止确认、专注计时，使用不同构图和浅色底材；每一步保留真实功能入口。
- 通知改期采用深绿整幅背景、书页线稿与米白通知卡。提前／延期切换、原文依据、时间轴变化和说明仍可操作。
- 全部功能以两列目录呈现，页尾使用大字、书本线稿与学习空间入口，形成完整的浏览节奏。

展示数据明确标为示例；首页交互只保存在当前组件内，不提交任务或更改真实学习数据。未新增用户数量、效率提升等未经验证的宣传数字。

主视觉使用内置 `image_gen` 一次生成全新图片。原图、副本、实际提示词及处理方式见 [素材说明](../../frontend/src/assets/decor/README.md)。没有外部图库或图片 CDN 依赖。

字体继续使用本地 Noto Sans SC 与 Manrope，保留 SIL OFL 1.1 原始许可。新增文案已补齐中文子集，现在中文 726 字、西文 214 字，两文件共 214,148 字节。详见 [字体与许可](../../frontend/public/fonts/README.md)。

`picture` 按断点选择图片，声明尺寸以预留布局空间。主图优先加载。新首页的样式与图片随 LandingView 加载；移除全局装饰文件中的旧首页背景规则，其他页面继续使用既有背景。

## 交互与可访问性

- 原有登录、注册、演示登录、登录后返回工作区的行为保留。
- 三步流程使用原生按钮及 `aria-pressed`，支持键盘 Enter／空格操作；面板带 `aria-live`。
- 保留跳到主要内容链接、唯一主标题、可见键盘焦点、图片替代文本与任务进度语义。
- 主视觉和下划线只在进入页面时播放一次；手账沿用进入视野后的一次翻页动作。没有循环动画或额外动画库。
- `prefers-reduced-motion` 下关闭本页 CSS 动画与过渡；手账指令仍有减少动态效果与中断清理的行为契约。此轮未切换操作系统的减少动态效果设置。
- 手机导航、品牌入口和改期切换的高度至少 44px；任务勾选标签和流程按钮有更大的整行点击区域。
- 检查的主要正文／背景对比度为 4.97:1–7.16:1；流程提示文字已加深。
