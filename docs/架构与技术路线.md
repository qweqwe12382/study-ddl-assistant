## 🧭 系统概览

学伴管家是一个面向单用户本地演示的学习资料、DDL 任务和复习计划管理应用。前端负责页面交互和状态展示，后端负责业务规则、文件解析、结构化抽取、数据持久化和导出。

## 🧩 核心组件

| 组件 | 代码位置 | 责任 |
| --- | --- | --- |
| Vue 前端 | `frontend/src/` | 页面路由、表单、上传、抽取确认、计划编辑和导出入口 |
| FastAPI 应用 | `backend/app/main.py` | 生命周期、CORS、请求日志、异常处理和路由注册 |
| API 路由 | `backend/app/api/` | 对外 HTTP 接口和请求级校验 |
| 业务服务 | `backend/app/services/` | 文件解析、DDL 抽取、Provider、任务和计划生成规则 |

| SQLite | `data/app.db` | 本地单用户业务数据和轻量迁移后的表结构 |
| 原始文件目录 | `data/uploads/` | 上传文件的 SHA-256 命名副本 |

## 🔄 主要业务流程

下面的流程对应最完整的演示主线：上传资料、解析、人工确认、任务闭环和复习计划。

```mermaid
sequenceDiagram
    accTitle: 资料到复习计划流程
    accDescr: 展示用户从上传资料开始，经过文件解析、DDL 抽取与人工确认，最终生成任务和复习计划的交互流程。

    participant user as 用户
    participant web_app as 前端
    participant api as FastAPI
    participant parser as 文件解析服务
    participant provider as 抽取 Provider
    participant database as SQLite

    user->>web_app: 选择课程资料并上传
    web_app->>api: POST /api/materials/upload
    api->>parser: 校验类型、大小、签名并提取文本
    parser-->>api: 解析文本或失败原因
    api->>database: 保存资料、哈希和处理状态
    api-->>web_app: 返回资料记录
    user->>web_app: 点击 AI 抽取
    web_app->>api: POST /api/materials/{id}/extract
    api->>provider: 生成候选任务
    provider-->>api: 结构化候选、来源片段和置信度
    api->>database: 保存待确认快照
    api-->>web_app: 返回抽取预览
    user->>web_app: 编辑并确认候选任务
    web_app->>api: POST /api/materials/{id}/extraction/confirm
    api->>database: 创建正式任务并保存确认快照
    api-->>web_app: 返回已确认任务
    user->>web_app: 选择课程并生成复习计划
    web_app->>api: POST /api/study-plans/generate
    api->>database: 读取资料、任务并保存计划
    api-->>web_app: 返回可编辑计划
```

## 🛡️ 可靠性边界

- 文件上传先做扩展名、MIME、大小、数量、空文件和文件签名校验，再写入本地目录
- 解析失败保留原始文件和失败原因，允许在资料页重试或手动补充正文
- 抽取结果先保存为预览，不会在未经人工确认时直接创建正式任务
- 低置信度、缺失日期、日期冲突和无法回溯来源片段的候选会标记为需复核
- Provider 默认使用本地规则实现，外部模型仅在配置 `LLM_API_KEY`、`LLM_MODEL` 后启用
- 服务启动时通过 `/api/health` 执行数据库连通性检查，并通过 `X-Request-ID` 定位请求日志
