## M3 优化——安全性与一致性

状态：已完成

- 手动资料接口不再允许客户端写入原始文件路径、哈希和处理状态等服务端字段；
- 上传增加单次文件数量限制、受限读取、原子写入和异常清理；
- 内容哈希增加唯一索引，降低并发重复上传风险；
- 删除资料时同步删除原始文件，重试时根据实际存储格式解析；
- 增加 DOCX 解压大小、图片分辨率和文本控制字符校验；
- 扫描版 PDF 增加页数受限的 OCR 兜底，并使用锁保护 OCR 引擎并发调用；
- 新增上传策略接口，前端动态读取文件大小、数量和格式限制；
- 前端支持手动补充解析文本和下载原文件。

## M4——AI 抽取与人工确认

状态：已完成，稳定性优化完成

已完成：

- 在 `Material` 中增加抽取状态、Provider、结果快照、错误原因和完成时间，并保留 SQLite 轻量迁移；
- 增加可替换的 `LLMProvider`，默认使用离线 `local-rules`，配置模型环境变量后支持 OpenAI-compatible Provider；
- 增加课程识别、任务类型、DDL、`source_quote`、置信度和 `need_review` 结构化结果；
- 对模型 JSON、日期、时间、相对日期、多日期、日期冲突和来源原文执行后端校验；
- 低置信度、缺失日期和异常结果只进入待确认预览，不直接创建正式任务；
- 完成“AI抽取—人工编辑—确认创建任务”的前端流程；
- 新增 9 个 M4 测试，覆盖正常抽取、缺失日期、日期冲突、非法 JSON、人工确认、重复抽取保护、元数据编辑、人工修改快照和英文日期。
- 修复已确认结果被误标记为失败的问题，保留外部 Provider 失败前的结果快照；
- 资料元数据编辑不再无条件重置抽取状态，确认结果会同步保存课程、资料类型、标签和人工修改后的任务；
- 前端打开已有结果时优先读取快照，已确认资料不再重复调用抽取；
- 为每次抽取增加批次号和候选任务 ID，并增加数据库唯一索引，降低并发确认造成重复任务的风险；
- 外部 Provider 增加可配置超时和重试次数；
- 日期解析增加英文月份、星期/周末、相对日期和上午/下午时间，并对过去日期和默认日终时间增加提示；

接口：

- `POST /api/materials/{id}/extract`；
- `GET /api/materials/{id}/extraction`；
- `POST /api/materials/{id}/extraction/confirm`。

验证：

- 后端 `pytest -q`：33 个测试通过；
- 前端 `npm.cmd run lint`：通过；
- 前端 `npm.cmd run build`：通过。

当前遗留问题：
