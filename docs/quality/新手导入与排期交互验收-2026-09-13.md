# 新手导入与排期交互验收 · 2026-09-13

本轮在工作区已有资料分类与计划范围改动上，重新整理 Web 的资料导入、固定日程和复习计划交互。

## 操作逻辑

| 想做什么 | 现在的操作 | 按需展开的功能 |
| --- | --- | --- |
| 放入资料、通知或提纲 | 添加资料 → 选文件或粘贴文字 → 保存并核对 | 手动填写、课程、分类、标题和参考时间 |
| 从资料安排复习 | 核对内容 → 安排复习 → 设置时间并生成 | 资料范围、同时加入待办、计划名称 |
| 只保存混合资料 | 仅整理资料 → 保留完成结果，可继续安排复习 | 原文、分类标签、识别依据 |
| 录入考试或上课时间 | 在当前表单选课程或新建课程 → 填主要时间 → 保存 | 考试名称、结束时间、座位、周次和备注 |
| 导入课表 | 选择接入方式 → 预览 → 确认导入 | 来源名称、学期周数；开学日从已保存设置带入 |
| 准备考试 | 考试卡点安排复习，自动带入课程和考试日期 | 更改每日用时、资料范围 |

文字资料没填标题时使用正文首行生成文件名。添加课程只需课程名，不再要求跳到设置页；已确认但未归课程的资料也能就地补课程。计划与资料往返传递日期和每日分钟数，刷新资料页后继续操作也保留这些参数。

## 保留的功能与边界

- 文件、文字和手动添加均可访问；保留批量上传结果、重试、原文、筛选、分类、标签、来源及完整管理。
- 资料保存与创建任务分开；只有确认加入的候选成为任务。“仅整理资料”不会创建候选任务。
- 未确认结果可展开更换识别方式，外部 AI 发送仍需明确确认。已确认结果展示只读任务，修改正文沿用已有重新处理流程。
- 计划仅使用明确选择的资料和待办，保留来源身份、版本、冲突提示及未排入项；清空后刷新不会擅自重新扩大范围。
- 生成按钮明确为“生成并保存计划”。保存后保留计划定位链接，刷新仍能看到生成结果。
- 已有计划文件作为复习内容参考重新排期，**不原样导入文件日期**。每日分钟数是单计划上限，**不会自动扣除课表占用或合并多个计划的容量**。
- 课表导入先预览再确认；确认使用的学期开始日期同时保存为周次定位依据，保存失败会单独提示。
