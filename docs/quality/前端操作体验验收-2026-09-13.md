# 前端操作体验验收 · 2026-09-13

本轮面向学生日常使用，优化 Web 总览、任务清单、资料收件箱、专注页和公共导航。保留八个页面、简洁/完整视图、原文来源、导出入口和人工确认流程。

## 参考与取舍

- [Linear 的界面重设计](https://linear.app/now/how-we-redesigned-the-linear-ui)：参考其导航、标题、面板的对齐与信息层级；把公共入口放到固定位置，减少页面间的不一致。
- [Linear 的快捷操作介绍](https://linear.app/learn/intro-to-linear)：参考可搜索的命令入口，落地为本地页面和常用动作导航。
- [Things](https://culturedcode.com/things/)：参考围绕当前任务组织内容的方式，采用轻量清单、勾选完成和就地反馈。

以上是设计方法参考，未复制第三方代码或品牌素材。设计使用 frontend-design 与 impeccable 的指南；后者辅助程序缺少引擎，未安装额外工具，依据指南与真实页面完成检查。

## 实现结果

| 区域 | 本轮变化 |
| --- | --- |
| 导航 | 桌面“快捷入口”和手机搜索按钮；Ctrl/Cmd K 打开，中文/英文关键词搜索，方向键选择，回车进入，Esc 关闭。已有弹窗打开时不叠加第二个快捷面板。 |
| 快捷动作 | 记任务、粘贴通知、进入专注；复用原页面流程。同页快速添加会聚焦输入框，跨页通知入口会打开通知编辑弹窗。 |
| 今日总览 | 日期替换重复引导语；当前任务和待确认事项在桌面并排，手机纵排；风险、截止与入口保持可见，详细解释按需展开。 |
| 任务清单 | 完成按钮改为有完整点击区域的圆形勾选；任务名可打开编辑，保留真实来源链接；完成后移动分组并显示可补充用时的反馈。 |
| 信息减负 | 简化通知、资料状态和空状态文案；复盘说明仅在展开后显示，移除旧装饰边框；任务筛选展开带过渡。 |
| 专注 | 简化提示，按开始/运行状态显示文案，计时保存规则可展开；开始、暂停、放弃与保存条件沿用原逻辑。 |
| 动效 | 页面淡入、筛选/复盘展开、按钮按压、任务变更与完成反馈；保留减少动态效果规则。 |

颜色延续 `#ffffff` 白色、`#f6f8f7` 浅灰绿、`#20392f` 深色文字、`#327864` 主色与 `#e0e8e3` 分隔线，风险色只用于风险。使用现有中文无衬线字体栈；固定字号、可见焦点、44px 为主要触控区域，避免增加依赖。
