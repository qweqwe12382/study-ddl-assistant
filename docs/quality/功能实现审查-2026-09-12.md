## 优先修复的问题

优先级：P1 为核心功能不可用或权限/关键时间解释错误，应优先处理；P2 为特定流程、输入或环境触发的错误。以下 F01–F06、F08–F20 已有代码与隔离行为证据；F07 为已复现但需要明确产品策略的联动缺口。它们不是 20 项端到端浏览器测试。

### F01 · P1 · 专注“仅记录用时”必然保存失败

位置：`frontend/src/views/FocusView.vue:262`；`backend/app/schemas/task.py:49`。

计时达到可保存门槛后，前端发送 `PATCH /tasks/{id}` 和 `actual_minutes`。后端 TaskUpdate 禁止额外字段，且没有该字段。携带正确版本的隔离请求返回 **422 / extra_forbidden**，实际分钟仍为空。现有 `test_m84_agent_feedback.py:71` 还明确要求此 PATCH 拒绝，说明两端功能约定不一致。

建议：为“记录专注但不完成任务”定义专门的业务操作，明确累计用时、剩余用时、活动和计划反馈规则，并补一次跨接口保存回归。

### F02 · P1 · DDL 通知会把未成立或无关的表达解释为变更

位置：`backend/app/services/deadline_radar.py:63`、`:88`。

“本次作业不取消”和“如因天气原因取消本次作业，将另行通知”均预览为取消；“提交方式调整为线上，答疑定于……”被预览为变更截止；多任务改期通知采用最后一个改期表达和日期。四例均 preview/apply **200**，保存状态或截止时间真实改变，版本从 1 升为 2。

界面仍要求用户核对确认，并非后台自动取消。但预览给出的变更解释本身错误，会误导用户执行。建议先拒绝否定、条件、非截止变更及多目标歧义，要求明确对应任务和新截止。

### F03 · P1 · 演示入口可能进入预先注册的同名管理员账号

位置：`backend/app/api/auth.py:71`、`:130`。

新实例先用 `demo@study.local` 注册，得到首个管理员账号；退出后，无密码调用演示入口，会复用这个账号并返回管理员身份；读取管理员配置 **200**。注册没有保留演示邮箱，演示登录也没有重验该用户是否为隔离的非管理员演示身份。

范围限定：演示接口仅在 `development/test` 开启，不能把这项证据表述成生产模式身份绕过。建议为演示身份使用不可被普通注册占用的独立标识，并验证非管理员、独立工作区约束。

### F04 · P2 · 先体验演示会导致首次正式注册没有管理员

位置：`backend/app/api/auth.py:77`。

新实例先演示登录，再正式注册：注册 **201**，但 `is_admin=false`；访问管理员配置 **403 ADMIN_REQUIRED**。首个用户判断统计了演示用户，后续正常注册也不会得到管理员，既有工作区认领同样受到影响。

建议：管理员引导明确排除演示身份，并测试两种首次使用顺序。

### F05 · P2 · 已取消任务可通过更新反馈变成已完成

位置：`frontend/src/views/TasksView.vue:219`；`backend/app/api/agent.py:618`。

详细任务表对 completed/canceled 共用“更新完成反馈”分支。普通完成接口对 canceled 返回 **409 TASK_CANCELED**，Agent 完成接口却返回 **200** 并保存 completed，绕过“先恢复任务”的状态约束。

建议：统一完成操作的状态校验；取消任务行提供恢复入口，并避免显示完成反馈按钮。

### F06 · P2 · 填写实际分钟会覆盖正确的任务完成计划差异

位置：`backend/app/services/agent_feedback.py:184`、`:303`。

任务已有复习安排，完成时填写实际 45 分钟：系统先产生 task_completed 差异，随后 actual_minutes_changed 将前者过期。最终唯一候选仍关联已完成任务；接受 **200** 后该任务仍在计划中。相同场景不填分钟，task_completed 差异能正常清除关联。

建议：以完成后的任务终态生成一致差异，避免反馈事件重新加入已完成工作。

### F07 · P2 · 接受一次计划差异后，该计划项的后续联动停止（产品策略需明确）

位置：`backend/app/api/agent.py:718`；`backend/app/services/agent_feedback.py:114`。

资料生成计划→新增任务→接受新增差异→完成任务，后续差异列表为空，计划仍关联此任务。接受差异改变正文而未更新 baseline；后续用当前内容等于原 baseline 作为可调整条件，因而排除此项。

“保护人工修改”是既有设计，但“接受过一次系统差异就永久退出持续联动”未明确写成产品边界。建议区分人工修改与系统接受的基线变更，或清楚呈现退出联动状态。

### F08 · P2 · 在任务编辑页延期后仍显示逾期

位置：`backend/app/api/tasks.py:148`；`backend/app/services/task_service.py:23`；`backend/app/api/dashboard.py:51`。

昨日截止的任务被同步成 overdue，经任务编辑使用的普通 PATCH 接口将截止改到两天后并重新读取，状态仍为 overdue。首页同时把同一任务放入逾期与即将截止列表，两项计数均为 1。DDL 应变台的改期路径已恢复该状态，这项缺陷不适用于所有改期入口。建议统一非终态任务的逾期状态重算。

### F09 · P2 · 外部 AI 的 ISO 时区字符串可提前 8 小时落库

位置：`backend/app/services/extraction.py:254`。

模拟 Provider 返回 `2026-09-18T12:30:00Z`，候选和正式确认后的任务均为 `2026-09-18T04:30:00Z`，提前 **8 小时**，且无警告。若来源写等价北京时间 20:30，则被判为多时间冲突，最终可保存空截止。

建议先按 ISO 日期时间和时区解析，再统一到 UTC；来源与 Provider 应比较同一时刻，避免对标准时间字符串重新进行自然语言扫描。

### F10 · P2 · 混合 PDF 会静默漏掉扫描页

位置：`backend/app/services/file_parser.py:162`。

两页合成 PDF，第一页文字封面、第二页图片：上传状态 processed，正文只有封面，OCR 调用 **0 次**。解析器一旦整本有任意文字便提前返回。模拟 OCR 用于验证是否调用，未用于证明真实 OCR 准确率。

建议逐页判断文字层；缺文字页执行 OCR 或向用户明确列出未处理页。

### F11 · P2 · 畸形 Provider 结果触发 500 且不记录失败状态

位置：`backend/app/services/extraction.py:102`、`:44`。

返回 `warnings:null` 且 source_quote 不存在时调用 `None.append()`，异常未进入 INVALID_PROVIDER_JSON 兜底。接口 **500 INTERNAL_ERROR**，资料仍 not_started 且 extraction_error 为空。建议在操作嵌套字段前校验类型，并统一记录抽取失败。

### F12 · P2 · “下午 3 点半”静默识别为 15:00

位置：`backend/app/services/llm_provider.py:110`、`:295`。

上传“请于2026年9月18日下午3点半提交作业”，候选截止为北京时间 **15:00**，应为 **15:30**，warnings 为空。建议补齐常见中文分钟表达，对未支持的表达提示复核。

### F13 · P2 · DDL 重放把旧回执与数字 ID 复用后的新任务绑定

位置：`backend/app/api/deadline_radar.py:83`；`backend/app/services/deadline_radar.py:210`。

执行取消→删除原任务→创建另一个复用数字 ID 的任务→重放原幂等请求：响应 **200**，task 为新任务，receipt.source_navigation_key 属于已删除旧任务。没有再次改动新任务，但返回对象与审计身份不一致。建议重放仍校验永久身份，或只返回旧执行的不可变结果。

### F14 · P2 · localhost 登录后原件下载因主机不一致返回 401

位置：`frontend/src/api/index.js:61`；`frontend/src/views/MaterialsView.vue:1532`。

普通请求会将本地 API 主机匹配为页面的 localhost，但 fileUrl 仍使用默认 127.0.0.1。执行实际 URL 生成函数证实主机不同；隔离会话上传同一合成文件后，localhost 原件请求 **200**，127.0.0.1 请求 **401**。建议原件 URL 复用统一 API 地址解析。

### F15 · P2 · 学校登录失败被当成网站登录失效

位置：`backend/app/services/njust_academic.py:222`；`frontend/src/api/http.js:53`；`frontend/src/auth/session.js:65`。

模拟学校密码/验证码错误返回 **401 NJUST_AUTH_FAILED**；运行当前前端拦截器，实际发出 study-auth-expired。会话监听清空网站登录用户，App 将转去登录页。这里是前端登录态被清空，并不表示后端网站会话被撤销。

建议区分网站鉴权失效与学校上游认证失败，使用户停留在学校导入表单内修正输入。

### F17 · P2 · ICS 多天重复把 COUNT 当成周数

### F18 · P2 · 跨午夜课程使 ICS 预览返回 500

### F20 · P2 · 可以创建在任何周都不可见的课表记录
