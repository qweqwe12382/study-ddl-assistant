# 资料与复习计划流程验收

日期：2026-09-13。范围：Web 与本地后端的识别、资料确认、计划来源选择和后续计划调整。

## 使用流程

1. **保存资料**：上传文件或粘贴文字，先解析正文并用本地规则识别。
2. **整理内容**：区分学习资料、已有复习安排、任务通知和混合内容。内容摘录取自原文；复习安排作为参考，原日期不直接成为新计划的日程或考试日期。
3. **单独确认任务**：明确提交、参加或完成的要求仍作为任务候选。没有任务时可确认保存资料；有候选时可选择“仅保存资料，不建任务”或勾选后创建任务。选中的课程会保存到资料上。
4. **选择复习范围**：新建计划时明确勾选资料，任务位于可选展开项中，默认不加入。通知与已有复习安排不默认勾选；正文不可用的资料不可选择。从单份资料进入时只预选该资料。
5. **设置时间并生成**：填写考试日期和本计划每日上限。空范围禁止生成；生成结果展示资料与任务数量，保留原有用时、截止、未排入反馈与来源导航。
6. **继续执行**：新建模式不混入旧计划风险提示。明确选择范围的计划不会因同课程下未选中的新任务收到插入建议；手工修改和差异接受仍保留范围元数据。

## 关键实现边界

- 无新增外部服务或依赖。外部 AI 仍需用户在本次操作中明确同意；本轮只验证本地规则和模拟外部提供方的服务端校验，未调用真实外部 AI。
- 新增 `GET /api/study-plans/sources?course_id=...`，返回可用性、默认建议以及来源不可变标识和版本。
- Web 生成请求总是提交 `material_sources`、`task_sources` 两个明确列表。服务端验证课程归属、来源标识、版本和可用性，空列表不展开为全课程。只传其中一类时另一类视为空。
- 兼容旧 API 调用：两个来源字段均省略时仍保留原先按课程生成的行为。已有计划快照不自动重写，历史确认任务不批量改动。
- `material_only=true` 表示明确舍弃本批候选、只保存资料；原本就无候选时也可直接确认。资料确认仍使用版本前提、事务和防重复确认。
- 内容摘录由服务端从正文提取，不采纳模型自称的知识点或字段来源。日期不作为复习计划导入功能；这里只提供参考资料与重新排期。

## 实际浏览器验收

在本地演示账号、1280×800 桌面与 390×844 手机视口完成：

- 粘贴带日期的复习安排，识别为“复习安排 · 参考”，无截止任务；保存后所属课程持久化。
- 从该资料进入计划，只预选该资料，其他资料及任务不选；生成结果为 1 份资料、0 条任务。
- 从普通新建入口进入，复习资料默认勾选，通知和已有复习安排默认不选。
- 取消全部选择，生成按钮禁用；只选择任务，按钮恢复可用。
- 手机上粘贴混合资料，学习内容与提交要求分开展示，截止及来源原文可见。
- “仅保存资料”后无创建任务入口，任务候选立即清空。修改本轮验收资料正文、重新识别并再次确认，复核了即时刷新修复。
- 最终用混合资料生成计划，日程内容包含正文学习点，不含提交作业；显示 1 份资料、0 条任务。
- 手机页面无横向溢出，最终检查期间无浏览器警告或错误。
