## ▶️ 执行步骤

在项目根目录执行：

```powershell
& .\.venv\Scripts\python.exe -m pip check
& .\.venv\Scripts\python.exe -m pytest -q --basetemp .\.pytest-tmp\final-check
Push-Location frontend
npm.cmd run lint
npm.cmd run build
Pop-Location
```

系统临时目录权限正常时，也可执行一键校验脚本：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-local.ps1
```

脚本通过的判定标准是：依赖检查、后端测试、前端 lint 和 production build 均成功。若系统临时目录被拒绝，应记录原始错误并使用仓库内 `--basetemp` 目录重跑；不得把首次未完成的脚本写成通过。若只执行单项命令，也应注明未覆盖的检查项。
