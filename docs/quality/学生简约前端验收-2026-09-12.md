# 学生简约前端验收（2026-09-12）

## 设计结果

- 页面使用白色内容区、浅灰绿背景、统一中文系统字体和绿色主操作，减少重复说明、嵌套卡片与装饰。
- 首页以“今天 / 先做这件事”为核心，资料入口和近期截止放在后面；详细来源和完整学习记录仍可打开。
- 任务列表收紧为信息与操作并排；资料页统一搜索和可展开筛选，视图切换保留条件。
- 八个页面完整保留。桌面分组侧栏，手机常用底栏与“全部功能”弹窗；当前页有明确标记。
- 保留“简洁视图 / 完整视图”及本地记忆，完整视图提供全部管理、统计、导出和记录。
- 专注未记录时，普通页面切换需选择继续或放弃；退出账号与登录失效不被计时守卫阻断。
- 普通账号遇到 `403 + ADMIN_REQUIRED` 时显示“由管理员管理”；其他错误继续明确提示。
