## 两步启动

Windows、Python3.14、Node.js24。在仓库根目录执行：

```powershell
& .\scripts\setup-reviewer.ps1
& .\scripts\start-reviewer.ps1
```

访问 <http://127.0.0.1:5173>，点击“体验示例空间”。无需注册和模型密钥。演示数据存放在`.tmp/reviewer-demo`；首次安装依赖需要网络。默认端口被占用时，可使用`-ApiPort 8018 -WebPort 5188`。

验证全部代码：`& .\scripts\verify-local.ps1`。单独复现隔离闭环：`& .\scripts\run-isolated-smoke.ps1`。正式用例TC01提供现场操作步骤。
