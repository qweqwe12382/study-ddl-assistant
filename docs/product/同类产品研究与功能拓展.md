# 同类产品研究与功能拓展

_研究日期：2026-09-05 · 适用项目：学伴管家 · 中兴赛道命题四"学习 DDL 与资料管理智能体"_

---

## ✅ 一句话结论

对标 Shovel（工作量引擎）、TickTick（任务+番茄钟+日历一体）、Classify（学生任务组织）等同类产品的结构与功能后，本轮补齐两项与比赛要求直接对应的短板：**一键演示模式**（满足"涉及登录的，应提供测试账号或演示模式"的提交硬性要求）与**专注计时器**（同类产品标配，且把真实用时接回估时校准闭环）；学伴管家的差异化仍然是"有依据、需确认、会校准"的智能体闭环，这是同类产品都不具备的。

## 🔍 同类产品结构与作用

| 产品 | 结构骨架 | 核心作用 | 对学伴管家的启示 |
| --- | --- | --- | --- |
| [Shovel](https://shovelapp.io/) | 课表 + 任务 + 时间预算看板 | 唯一主打"工作量引擎"：扣除上课、睡眠等固定时间后，告诉学生"来不来得及"，并在落后前预警；近期加入学习连续天数（streak）追踪 | 本项目的学习容量、七日/单日风险、同日多 DDL 检测已覆盖其核心价值，且多了"可确认的重排建议" |
| [TickTick](https://ticktick.com/) | 任务 + 日历 + 四象限 + 番茄钟 + 习惯 | 通用效率一体化；任务可直接挂 25 分钟专注计时，计时数据反哺任务统计 | 专注计时是学生高频预期功能，此前缺失 → 本轮补齐，并把用时接入"会校准"闭环 |
| [Classify](https://classify.org.uk/) | 科目 + 作业清单 + 班级群聊 | 面向中学生的轻量组织器；提供免打扰"冲刺模式" | 免打扰专注是真实需求，本项目的专注计时页不引入社交，保持个人学习闭环 |
| [MyStudyLife](https://www.focuswindow.app/blog/best-study-planner-apps) | 课程 + 作业 + 考试最简计划器 | 低成本记录课业 | 本项目课表考试页已覆盖，且多了教务 iCal/NJUST 接入 |
| Structured / 滴答清单日历视图 | 时间轴日程 | 把一天可视化 | 任务页 DDL 时间议程（M8.24）已是同一思路 |

共性结论：同类产品的页面结构普遍是"总览仪表盘 + 任务清单 + 日历 + 专注/统计"，但它们都把建议直接执行或不解释来源；学伴管家把"感知—判断—建议—确认—执行—反馈"做成一等公民，是评审视角下的差异化主线。

## 🚀 本轮功能拓展

### 拓展一：一键演示模式（`POST /api/auth/demo-login`）

- **动机**：比赛明确要求登录类作品提供测试账号或演示模式；同时评委从注册到看到完整闭环的成本需要降到一次点击。
- **行为**：登录/注册页新增"一键体验演示模式"。后端找到或创建共享演示账号 `demo@study.local`（固定密码 `XuebanDemo2026`，始终非管理员、独立工作区），向其工作区幂等播种确定性演示数据（复用 `ensure_demo_data`），建立会话并设置 HttpOnly Cookie；前端直接进入学习总览。
- **边界**：仅 `APP_ENV=development/test` 提供，生产环境返回 404 `DEMO_DISABLED`；演示账号不能访问实例配置；真实账号数据不受影响。
- **验证**：新增 3 项后端测试（账号复用与会话、工作区幂等播种、生产禁用）；隔离页面实测登录页点击 → `/app` 以"演示同学"进入，收件箱与任务出现演示数据。

### 拓展二：专注计时器（`/focus`）

- **动机**：番茄钟是同类产品（TickTick、Classify、Forest 等）验证过的学生高频功能；更重要的是把"这次实际用了多久"接回已有的课程估时校准与学习节奏信号，强化"会校准"的智能体故事。
- **行为**：桌面侧栏与任务页提供入口。选一个待办任务、选 15/25/45 分钟预设、开始/暂停/结束；专注满 15 分钟后可"完成并记录"或"仅记录用时"，用时与任务已有实际用时合并后经既有 API 写入，携带 `If-Match` 乐观锁；不足 15 分钟诚实提示不记录。计时只存在于当前页面。
- **边界**：不做番茄钟统计历史、不打断提醒、不自动完成任务——记录动作仍由用户确认，遵守"计划调整始终由你确认"的产品边界。
- **验证**：纯逻辑抽出 `utils/focusTimer.js` 并新增 `focus:check` 契约测试（时钟格式化、可记录判定、用时合并上限）；页面纳入 `npm run verify` 构建 gzip 预算（JS 2.96 KiB / CSS 1.19 KiB）；隔离页面实测开始/暂停/结束状态机与不可记录分支。
